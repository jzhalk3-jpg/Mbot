Messenger Pro - Single File Prototype

1) فك الضغط.
2) افتح index.html في المتصفح.

هذا مشروع Single-File يعمل محلياً ويشمل واجهة مراسلة، محادثات، رسائل، مجموعات، قنوات، بحث، ملفات، أرشفة، تثبيت، رسائل محفوظة، إعدادات، وضع ليلي، وتخزين محلي.

ملاحظة مهمة:
النسخة تعمل بالكامل داخل المتصفح، لكن الميزات التي تحتاج خادماً حقيقياً مثل:
- تسجيل الدخول الفعلي OTP
- تعدد الحسابات الحقيقي
- قاعدة بيانات مشتركة
- الرسائل الفورية بين مستخدمين مختلفين
- WebSocket
- رفع الملفات إلى Cloud Storage
- Push Notifications
- المكالمات الصوتية والفيديو
تحتاج Backend وDatabase، ولا يمكن تنفيذها بشكل حقيقي بالكامل في ملف HTML واحد فقط.

يمكن رفع هذا الملف مباشرة على استضافة ثابتة للتجربة.
