# بوت بيع الأرقام الوهمية

بوت تلغرام لبيع أرقام وهمية لتلغرام وواتساب، مع نظام رصيد يدوي وزيادة سعر مخفية (50%).

## الميزات
- اختيار الخدمة (تلغرام/واتساب).
- عرض قائمة الدول المتاحة.
- شراء رقم مع زيادة السعر (مخفية عن المستخدم).
- نظام رصيد يدوي للمشرف.
- أوامر إدارة للمشرف.

## التشغيل
1. تثبيت المكتبات: `pip install -r requirements.txt`
2. تشغيل البوت: `python3 bot.py`

## الأوامر
- `/start` - بدء البوت
- `/buy` - شراء رقم
- `/balance` - عرض الرصيد
- `/addbalance` (للمشرف) - إضافة رصيد للمستخدم
- `/setprice` (للمشرف) - تعديل نسبة الزيادة
